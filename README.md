
# My Metroidvania

Hey! This is a 2D Metroidvania I'm making in Godot.

I'm developing it step by step over the next few weeks, starting with the basic movement and camera before moving on to combat, enemies, and exploration.

## What's done so far?

- Player movement and jumping
- Camera deadzone and lookahead
- Player states connected to movement
- HurtBox and HitBox classes extending Area2D node
- Simple player attack
- Attack Dummy to test attacks on

The game is still in its early stages, so there's not much to show yet. I'm currently focusing on getting the basic mechanics working before spending too much time on art and other details.

## What's next?

- Make some player sprites and animations
- Add attacking and my first enemy
- Start building the actual level
- Add exploration mechanics and new abilities

## Made with

- [Godot Engine](https://godotengine.org/)
- GDScript
- Krita (Assets)

## How to run

1. Download or clone this repository.
2. Open the project in Godot.
3. Import `project.godot` if prompted.
4. Run the game.

I'll keep updating the project as I work on it and hopefully turn this prototype into a proper little Metroidvania.

It's a work in progress, so things will probably change along the way!
